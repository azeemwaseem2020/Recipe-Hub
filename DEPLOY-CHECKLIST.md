# RecipeHub deployment checklist

1. Confirm GitHub Pages is publishing the `main` branch root.
2. Confirm HTTPS and the final public URL.
3. Test homepage, recipes, categories, collections, guides, blog, privacy and disclaimer.
4. Test the custom 404 page.
5. Confirm mobile navigation and recipe filtering.
6. Generate sitemap.xml using the real production origin.
7. Add sitemap URL to robots.txt.
8. Verify the site in Google Search Console and Bing Webmaster Tools.
9. Test representative recipe URLs for indexability and structured data.
10. Review external image licensing/attribution before commercial use.

Image generation is intentionally deferred.
